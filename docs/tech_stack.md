# Stack notes

1. **Start with a modular monolith.** One FastAPI app with clear service modules, plus one Celery worker image. Split only when measurements justify it.
2. **Use Postgres for almost everything.** Relational data, JSONB for flexible payloads, pgvector for retrieval, and pg_cron or Celery beat for scheduling. Add Redis only for queues.
3. **Keep the LLM behind one client.** This makes evaluation, cost tracking, model swapping, and mocking straightforward.
4. **Run local models where data is sensitive.** Whisper and the embedding model can run locally, which keeps student recordings inside your infrastructure.
